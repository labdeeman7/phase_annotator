Before marking Completed

  1. Review the entire available timeline.
  2. Confirm there are no accidental rapid fragments or misplaced boundaries.
  3. Check uncertain intervals and add a neutral note where useful.
  4. Confirm the correct video name and Cholecystectomy ontology.
  5. Select Annotation → Mark complete.

Return files

The application saves <video filename>.phase-annotations.json beside the video. Copy each completed JSON into 05_Return_Annotations_Here. Do not rename the video or JSON and do not edit JSON manually.

Shared-five rule: annotate independently. Do not copy another annotator's boundaries or resolve disagreements together until both sets have been returned.

What happens next

Tosin will verify that files load, measure phase and boundary agreement, and organise clinical review of meaningful differences. Disagreement is evidence about the protocol; it is not automatically an annotator error.
