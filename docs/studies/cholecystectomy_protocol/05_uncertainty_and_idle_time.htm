Partial recordings

Annotate only what is visible. Begin with whichever phase is already occurring and end when the supplied recording ends. Do not invent missing beginning or ending phases.

Inactive periods

Preserve the original timeline; do not cut inactive periods out before annotation.

  • If operative context remains clear, continue the current phase.
  • If a prolonged pause is important, add a short neutral note.
  • Do not guess whether an invisible delay relates to equipment, staffing or another cause.
  • A separate future idle-time analysis can be created without changing the seven primary phases.

Undefined

Use Undefined for smoke, occlusion, corrupted footage, an out-of-body view, or loss of task context that prevents confident assignment. Also use it for purposeful gallbladder drainage under the documented interim rule, always with the standard note. Do not use it merely because a phase is difficult, long, repeated or uses unfamiliar instruments.

Why drainage is being retained separately

Kirtac et al., Surgical Phase Recognition: From Public Datasets to Real-World Data (Applied Sciences, 2022;12(17):8746), treated gallbladder drainage as an additional phase absent from Cholec80. OAUTHC will review its frequency, duration and boundary reliability before changing the current ontology.
