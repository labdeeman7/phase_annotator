# Cholecystectomy Protocol HTML Source

Open `OPEN_PROTOCOL.htm` to review the multi-page draft protocol. The maintained generator is `scripts/build_cholecystectomy_protocol_site.py`.

The repository copy deliberately does not duplicate clinical or Cholec80 video files. Its video players expect a sibling `clips/` directory containing the named transition clips. The distributable shared-study copy is generated inside `03_Cholec80_Training_Material`, where those clips already exist and the video pages work offline.

Current scope:

- Cholec80 seven-phase reference convention;
- explicit OAUTHC P1-to-P2 task-based adaptation;
- complete/partial-recording rules;
- inactive-period and Undefined guidance;
- transition-centred video examples;
- completion and return workflow.

This remains a draft. Revise it after comparing the five independently annotated shared cases.
