Draft for shared annotation

This protocol uses the seven Cholec80 phases as its reference convention, with a small number of explicit OAUTHC adaptations where the pilot annotations exposed a reproducibility problem.

Purpose

Use this protocol to label the dominant visible operative activity throughout each available laparoscopic cholecystectomy recording. The resulting timelines will support inter-rater analysis and evaluation of models trained on Cholec80.

Reference

Retain the Cholec80 seven-phase vocabulary so results remain comparable with established research.

Clinical adaptation

Do not let instrument appearance alone override the visible surgical objective, especially at the P1-to-P2 boundary.

Evidence

Use transition-centred clips to learn where labels change. Video evidence is more useful than isolated representative frames for temporal boundaries.

Seven phases

IDPhasePrimary question
P1PreparationIs the surgeon obtaining access and exposure?
P2Calot triangle dissectionIs focused hepatocystic-triangle dissection the sustained objective?
P3Clipping and cuttingAre cystic structures being occluded and divided?
P4Gallbladder dissectionIs the gallbladder being separated from the liver bed?
P5Gallbladder packagingIs the specimen being placed into a retrieval bag?
P6Cleaning and coagulationIs inspection, irrigation, suction or haemostasis now dominant?
P7Gallbladder retractionIs sustained specimen withdrawal/extraction occurring?
Status: this is a working protocol. The shared five cases are intended to reveal where two informed annotators still interpret it differently.
