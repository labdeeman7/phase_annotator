# Rule 01: Agent Engineering Discipline

## General Behavioral Rules

1. **Inspect before changing**: Inspect existing files and structure before altering architecture or proposing changes.
2. **Never claim success without testing**: Never say tests pass unless you executed them in the environment and received a passing exit code.
3. **Small, incremental changes**: Prefer small, understandable, logical increments over huge codebase rewrites.
4. **Preserve code & context**: Do not delete existing implementations without a clear rationale and discussion.
5. **State Tracking**: Keep `docs/TASKS.md` updated as progress is made so any developer or agent can resume without context loss.
